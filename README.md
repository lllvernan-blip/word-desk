# 单词翻译练习台

一个纯静态的背单词工具。选词 → 看释义 → 拼写 → 验证，数据全部存在浏览器本地，不上传。

## 在线访问

部署在 GitHub Pages：

https://lllvernan-blip.github.io/word-desk/

首次打开需要联网加载一次词库和程序，之后可以离线使用（PWA）。

## 功能

- 三个视图：练习、词库、进度
- 三个方向：英译中、中译英、听音拼写
- 内置词库：核心 3000 词 + 六个扩展词库（四六级、考研、GRE、雅思托福、专八、混合大词库）
- 自建词条：新增或导入 CSV / TXT / JSON 词表
- 学习记录：复习进度、错题本、热力图、掌握度分布
- 本地备份：一键导出、导入 JSON

## 数据与隐私

所有学习数据存在你当前这台设备的浏览器里（IndexedDB，降级到 localStorage）。

- 没有账号，没有服务端
- 默认不上传任何数据
- 进度页里有一个可选的上报端点，默认关闭，只有你自己填了地址并打开开关，事件才会 POST 出去
- 清除站点数据会丢掉全部记录，重要进度请先用「导出本地备份」

## 音频

单词发音是预先合成的 MP3，打包成 73 个分片文件。播放时用 HTTP Range 只取当前这个词那几百字节，不会整包下载。

## 部署

本站构建产物在 `dist/`，直接由 GitHub Pages 从该目录提供，没有构建步骤。

```bash
# 本地预览
cd dist && python3 -m http.server 8080
```
