# 单词翻译练习台

一个纯静态的背单词工具。选词 → 拆解词缀 → 猜义 → 验证 → 拼写，数据全部存在浏览器本地，不上传。

## 在线访问

部署在 GitHub Pages：

https://lllvernan-blip.github.io/word-desk/

首次打开需要联网加载一次词库和程序，之后可以离线使用（PWA）。

## 功能

- 三个视图：练习、词库、进度
- 三个方向：英译中、中译英、听音拼写
- 内置词库：3400 词（400 精选 + 3000 ECDICT 核心）；另有六个按需加载的扩展词库（四六级、考研、留学、GRE、专八、考博）
- 自建词条：新增或导入 CSV / TSV / TXT / JSON 词表
- 学习记录：复习进度、错题本、热力图、掌握度分布
- 本地备份：一键导出、导入 JSON

## 数据与隐私

所有学习数据存在你当前这台设备的浏览器里（IndexedDB，降级到 localStorage）。

- 没有账号，没有服务端
- 默认不上传任何数据
- 进度页里有一个可选的上报端点，默认关闭，只有你自己填了地址并打开开关，事件才会 POST 出去
- 清除站点数据会丢掉全部记录，重要进度请先用「导出本地备份」

## 音频

单词发音是预先合成的 MP3，打包成 73 个分片文件。播放时用 HTTP Range 只取当前这个词那几 KB，不会整包下载。

## 部署

线上站点由 GitHub Pages 提供，源分支是 `gh-pages`，内容等于 `dist/`。仓库没有构建步骤：`dist/` 就是源码。

```bash
# 本地预览
python3 -m http.server 8080 --directory dist

# 发布：先提交（脚本要求工作区干净），再跑唯一部署入口
git add dist && git commit -m "上线：改了 xxx"
bash deploy.sh

# 只想自检、不推送
DRY_RUN=1 bash deploy.sh
```

`deploy.sh` 只校验和推送，不改文件：工作区不干净、`sw.js` 缓存版本没递增、`app.js` 版本没变成新版本、外壳资源改了却没升 SW 版本、`dist/` 资源缺失、音频索引与分片对不上，都会直接报错并停止。
