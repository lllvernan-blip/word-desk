## 同日续十三（分组色只上字，不上胶囊框）
- 用户纠正：分色指的是字体颜色，不是胶囊框的颜色。此前 .chips-* 规则给未选中标签染了边框色，属于误读。
- 改为只设 color：.chips-pre/.chips-suf/.chips-root 的 :not(.expand):not(.active) 各自只保留 color: var(--pre)/var(--suf)/var(--brand)，background 与 border 回落到 .chip 默认的 --sheet 与 --line，删掉三条 hover 染色规则；展开胶囊边框也从 --brand-line 改为 --line-strong，仅文字保留品牌绿。
- 选中态仍为实色填充（框色=分组色），作为唯一的状态反馈保留；若用户要求连选中态也不上框色，可继续改。
- 实测：三组标签 color 分别为 rgb(53,89,140) / rgb(162,81,46) / rgb(31,90,68)，border 全部 rgb(224,218,201)，background 全部 rgb(251,248,240)；展开按钮 border rgb(200,192,171)。sw.js v18→v19，node --check 通过，无脚本异常。
- 用户再反馈「胶囊颜色还是跟词根字体同色」。根因有二：① .chip .n 与 .rz 用 color:inherit 跟随分组色，整颗胶囊看上去都带色；② 展开胶囊文字用 --brand，每个分组里都有一颗墨绿字胶囊。修正为数字与释义统一 --muted、展开胶囊常态字色 --muted 边框 --line（hover 才转品牌绿），选中态数字仍 color:inherit 配实底。sw.js v19→v20。
- 实测最终态：主词色 rgb(53,89,140)/rgb(162,81,46)/rgb(31,90,68)，三组背景全 rgb(251,248,240)、边框全 rgb(224,218,201)、数字与释义全 rgb(109,116,106)，展开胶囊字色同灰。分组色只落在主词上。
