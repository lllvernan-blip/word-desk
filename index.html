从备份恢复

第一次用？三步就能开始

这不是词典，而是「选词 → 拆解 / 猜义 → 验证 → 拼写」的练习。词来自本机词库，不上传。

  1. 选词：按前缀 / 后缀 / 词根筛选，或直接用全库；上方会显示命中多少词。
  2. 练习：每轮按四阶段走，先看词缀，再猜义，验证后拼写。
  3. 复习：练过的词按记忆曲线回来复习；进度页可导出本地备份。

数据只存这台设备；清除站点数据会丢失，重要进度请导出备份。

数据与隐私

存什么：复习进度（SRS）、错题本、每日统计、自建词、屏蔽词、设置，以及本机埋点事件。

存哪里：只在这台设备的浏览器里（IndexedDB / localStorage）。没启用 IndexedDB 时会临时存 localStorage。

是否上传：默认不上传。只有你在「上报设置」里填写端点并打开开关，事件才会 POST 到该地址。

怎么删：下方「清除本机全部数据」，或在浏览器设置里清除本站点数据；清除后进度不可恢复，内置词库仍在。

备份：进度页「导出本地备份」生成一个 JSON 文件，换设备时用「从备份恢复」。

埋点：只记录打开、开局、导入等关键事件，最多保留 1200 条；匿名，无账号或设备标识。
